# Changelog

## 1.1.5

- Open-source Marshell release built on the modular Next.js + Tauri 2 monorepo (`packages/core`, `packages/ui`, `packages/i18n`).
- Includes multi-pane native terminal workspaces, responsive preview browser, background process monitor, and Kanban board/list views.
- Supports 40+ OKLCh themes, light/dark modes, keyboard shortcuts, and 10 UI languages.
- Connects desktop sign-in via the web-portal callback flow on `marshell.bond`.
