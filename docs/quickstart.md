# Quick start

## 1. Open a project workspace

Launch Marshell and click **New Workspace**. Pick a local project folder and choose the number of terminal panes you want in the grid. Two panes work well for running a development server alongside a shell.

## 2. Work with terminals and processes

- Open shells, run builds or test suites, and split or focus panes using keyboard shortcuts.
- Open your project directory directly in your preferred external editor (VS Code, Cursor, Zed, or Sublime Text).
- Use the **Processes** drawer to monitor running servers started in the workspace and open active ports in the preview.

## 3. Preview your app

Switch to **Preview** to open your local dev server URL. Test mobile, tablet, or desktop viewport sizes and inspect rendered page elements.

## 4. Track tasks on the board

Switch to **Board** to organize project tasks across columns or in the sortable list view, complete with priorities, subtasks, labels, and dependencies.
